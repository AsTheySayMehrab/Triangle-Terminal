# Changelog

## 0.1.0 — Unreleased preview

- Windows PowerShell, CMD, and optional PowerShell 7 sessions backed by ConPTY.
- English/Persian UI, shaped bilingual editor and reader, ZWNJ insertion, and a Unicode-preserving PowerShell send path.
- Startup ASCII art, customizable appearance, editable AI command shortcuts, and a CLI launcher.
- Four previewable themes plus optional Windows Acrylic material with blur, opacity, noise amount, and noise scale controls.
- Terminal-first layout with opt-in bilingual reader, compact telemetry, and reduced-transparency fallbacks.
- Session/work timers, battery status, system memory, project selection, and transcript export.
- Unit and desktop integration tests, Windows CI, and a portable build workflow.

Known limits: third-party full-screen terminal apps do not have universal RTL cursor support; AI balances and usage limits are not integrated; macOS/Linux builds, code signing, and automatic updates are not supported.
